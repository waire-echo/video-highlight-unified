# 团队协作

main 是唯一维护主线；配置与版本清单选择算法路线，每次实验用独立 ID 和产物目录。一次开发使用 feat / fix / exp 分支，通过 PR 和自动检查后合入 main，再删除已合并的开发分支。

当前推荐入口是 scene_general_v3 的 `vh.py workflow`。先读 [README](../README.md) 和 [项目管理](project_management.md)，功能位置查 [功能索引](feature_index.md)。旧 E1/E2/E3、YOLO/Pose 和其他研究路线保留明确的各自入口。

分支、默认版本、CI、主分支保护限制、发布和回滚见 [分支规则](branch_policy.md)。新增算法使用独立源码目录和新版本清单；已有 core、Prompt、v3、帧号和 PTS 不改。维护分支名称不是运行时 version ID。

有解释价值的失败结论可以写入文档；缓存、完整预测、视频、权重和机器背景不提交 Git。外部正式产物保存版本、路径和 SHA256。本次任务临时文件在验收后删除，实际实验资料按实验规范保留。

正式提交来自自动流程。开发人工/外部模型参考在 notes 注明来源。本次整理不提交比赛官网，也不删除旧仓库。
